# 第五人格 · 监管者随机抽取器

一个单文件的网页小工具：从 36 名监管者中**不放回**地依次抽取 10 名，用翻牌动画逐个揭晓结果。

全部内容都在 `index.html` 一个文件里，无需安装、无需联网、无需构建，双击即可运行。

## 功能

- **不放回抽取**：抽中的监管者会从奖池中移除，10 次抽取结果保证互不重复。
- **翻牌动画**：每个槽位是一张 3D 翻转卡牌，点击「抽取下一位」后翻面显示角色名。
- **实时计数**：顶部显示「已抽取 / 10」和「奖池剩余 / 36」。
- **奖池总览**：底部列出全部 36 名监管者，已抽中的会置灰并加删除线，刚抽到的那位用金色边框高亮。
- **重新开始**：一键清空结果、重置奖池，可反复抽取。
- **响应式布局**：宽屏每行 5 个槽位，窄屏（≤640px）自动变为每行 2 个。

## 使用方法

直接用浏览器打开 `index.html` 即可：

- **Windows**：双击文件，或在浏览器中拖入。
- **命令行**：`start index.html`

点击「抽取下一位」抽出一名监管者，抽满 10 名后按钮自动禁用并提示完成；点击「重新开始」进入下一轮。

## 自定义

角色名单和抽取数量都是脚本顶部的常量，改完保存刷新页面即可生效。

**增删角色** — 修改 `HUNTERS` 数组：

```js
const HUNTERS = [
  "厂长", "小丑", "鹿头", "杰克", "蜘蛛", "红蝶",
  // ... 按需增删
];
```

槽位、奖池标签、计数器都由这个数组在运行时生成，**只需改这一处**，其余界面会自动同步。新增角色时建议保持「按上线顺序」排列，与现有列表一致。

**修改抽取数量** — 修改 `DRAW_TOTAL`：

```js
const DRAW_TOTAL = 10;
```

注意 `DRAW_TOTAL` 不应大于 `HUNTERS` 的长度，否则无法抽满。

## 实现说明

页面没有任何依赖（无框架、无 CDN、无外部图片或字体），CSS 和 JS 全部内联。

### 状态

只有两个状态变量，都是普通数组：

- `pool` — 当前还没被抽走的角色。
- `drawn` — 已抽中的角色，按抽取顺序排列。

### 三个核心函数

| 函数 | 作用 |
| --- | --- |
| `draw()` | 从 `pool` 中随机取出一个（`splice` 实现不放回），压入 `drawn`，然后调用 `render()` |
| `reset()` | 用 `HUNTERS.slice()` 重新填充 `pool`，清空 `drawn`，然后调用 `render()` |
| `render()` | 唯一的「状态 → 界面」同步入口：更新槽位翻面、计数、奖池高亮、按钮禁用状态和提示文案 |

`render()` 是单一的数据渲染出口 —— 新增任何界面状态时，请在 `render()` 里统一处理，而不要直接写进事件回调，否则状态和视图容易不同步。

另外两个函数 `buildSlots()` 和 `buildChips()` 只在页面初始化时各调用一次，负责生成 10 个卡牌槽位和 36 个奖池标签；之后的内容更新全部由 `render()` 负责。

### 动画

翻牌效果是纯 CSS：`.slot` 提供 `perspective`，`.slot-inner` 使用 `transform-style: preserve-3d`，加上 `.flipped` 类后旋转 `180deg`。正反两面通过 `backface-visibility: hidden` 互相遮挡，过渡曲线为 `cubic-bezier(.2,.7,.2,1)`，时长 0.55s。

### 配色与字体

深色木质底 + 金色描边 + 绯红按钮的暗色调，颜色统一放在 `:root` 的 CSS 变量里（`--gold`、`--crimson`、`--card` 等），想换配色直接改变量即可。字体优先使用衬线体（Georgia / 宋体）以贴合哥特风。

## 兼容性

代码只使用了现代浏览器通用的标准特性：CSS 变量、Grid 布局、3D transform、`aspect-ratio`，以及 ES6 的箭头函数与模板字符串。Chrome、Edge、Firefox、Safari 的较新版本均可正常使用。
